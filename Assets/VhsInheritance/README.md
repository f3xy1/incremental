# VHS Inheritance Prototype

Играбельный single-scene прототип видеосалона 90-х.

## Управление

- `WASD` — движение.
- `E` — взаимодействие.
- `E` у стойки утром — открыть улучшения; повторное `E` или `Esc` — закрыть меню.
- `E` у пустых рук на полке — открыть выбор кассет; нажмите на нужный слот.
- `Shift + E` у полки — забрать ещё кассеты, когда руки уже заняты. Порядок выбора сохраняется.
- `ПКМ` — осмотр верхней кассеты в руках.
- `Esc` — пауза / закрытие открытого меню.

## Цикл

`MorningPrep → DayPlay (480 сек.) → DayResults → EveningPrep → NightPlay → дверь → новый день`.

Все балансные значения и цены находятся в `Assets/VhsInheritance/Resources/VhsGameConfig.asset`.
JSON-сохранение: `Application.persistentDataPath/vhs_inheritance_save.json`.
Есть резервная копия `.bak`; если основной JSON повреждён, игра загружает её. Сохраняются текущая фаза, таймеры и очередь, инвентарь игрока, кассеты помощника и свойства кассет, возвращённых в полный аппарат. Чужая кассета выдаётся в руки и расходуется после просмотра.

## Запуск

- В Unity откройте `Assets/VhsInheritance/Scenes/VhsSalon.unity` и нажмите Play.
- Windows: `Builds/VhsInheritance/VhsInheritance.exe`. Для переноса копируйте всю папку билда, включая `VhsInheritance_Data` и DLL.
- В главном меню выберите «Новая игра». Утром можно подойти к стойке улучшений слева внизу или сразу начать смену кнопкой справа внизу.

Интерфейс выполнен на uGUI: округлённые панели, десять рисуемых кодом векторных иконок, список заказа со шкалой терпения, выбор конкретных слотов и осмотр кассеты. Сцена строго 2D, статичная камера показывает салон целиком; во время ночной записи камера приближается к ТВ. Графика не использует imagegen.

## Editor debug

- `F6` — перейти к следующей фазе цикла (только Editor).
- `F7` — добавить `$100` (только Editor).
- `Tools/VHS Prototype/Build Prototype Scene` — пересобрать bootstrap-сцену.
- `Tools/VHS Prototype/Validate Prototype` — проверить сцену и 10 веток улучшений.
- `Tools/VHS Prototype/Build Windows Player` — собрать обычный Windows-билд (DirectX 11).

Оформление вдохновлено Mr Records: мягкие мультяшные силуэты, тёмные контуры, пастельная мебель и округлый шрифт Nunito с кириллицей. 40 спрайтов нарисованы геометрией без imagegen. SVG-оригиналы находятся в `Art/Cartoon`, PNG для игры — в `Resources/Art/Cartoon`.

Куча состоит из отдельных объектов `VhsPileCassette`, по одному на сохранённую кассету. Новые кассеты вылетают из аппарата, при подборе удаляются только забранные объекты, оставшаяся куча перестраивается. Коллизии мебели — узкие `BoxCollider2D` у основания; игрок обходит их, а за верхней частью спрайта может пройти. Помощник строит маршрут по тем же коллайдерам.

Количество кассет на полках, в куче и внутри аппарата видно только в инспекторе контроллера и подписях Scene View при его выделении. В Game View и билде счётчиков нет. Вместимость рук и список заказа остаются в HUD.

Перерисовать PNG/SVG: `python AgentScripts/draw_cartoon_art.py` (Python, Pillow, aggdraw). После изменения параметров импорта выберите `Tools/VHS Prototype/Import Cartoon Art`. Лицензия шрифта: `Art/Fonts/OFL.txt`. Эти инструменты нужны только разработчику; билд не зависит от Python.

## Проверки

- Пять NUnit-проверок: конфиг, JSON, сохранение кассет с их свойствами, маршрут помощника и непроходимая стена.
- `AgentScripts/VhsAcceptance.cs` запускается в Play Mode через Unity CLI. Проверяет сортировку, отсутствие повторной оплаты, выбранные слоты, заказы, очередь, терпение, переполнение, автосохранения, чужую кассету и ночную дверь. Метод `UpgradesAssistantAndFourDays` проверяет все десять веток, реальную доставку помощником и четыре полных дня. Метод `FinishPlayback` проверяет завершение настоящей корутины ТВ.
- `AgentScripts/VhsCartoonAcceptance.cs`: реальные нажатия E/Esc и WASD, доступность точек взаимодействия, рост и уменьшение кучи 1/12/40/85, сохранение объектов оставшихся кассет, анимация аппарата и отсутствие лишней кассеты после JSON-загрузки. Метод `Run` запускает корутину, результат записывается в `Temp/verification/cartoon-acceptance.json`.
- Пример: `unity command script run --caller plugin --skill unity-cli -- --file AgentScripts/VhsAcceptance.cs --entry VhsAcceptance.Run`. После завершения записи вызовите `VhsAcceptance.FinishPlayback` той же командой.
- Проверки используют отдельные JSON-слоты в `Temp/verification`, не основной слот игрока.
- Проверка отдельного приложения: `AgentScripts/BuildSmoke.cs` создаёт тестовый билд в `Temp/VhsPlayerSmoke`, `AgentScripts/RunSmoke.ps1` запускает его и проверяет отчёт. Сцена, спрайты, шрифт и куча проверяются внутри приложения; камера сохраняет кадр через RenderTexture. Код этой проверки включается только флагом `VHS_PLAYER_SMOKE` и отсутствует в обычном билде.

## Принятые допущения прототипа

Стойка улучшений находится слева внизу; ТВ — рядом с аппаратом; незнакомец появляется у нижней двери. Ночь активируется при подходе к ТВ после получения кассеты. До просмотра дверь показывает подсказку и не завершает день. После четырёх авторских фрагментов используются нумерованные архивные записи. Формулы оплаты и прогрессии остаются черновыми значениями для плейтеста.
